# 꼭 해야 할 일 (TodoList 웹앱)

작은 실천으로 채우는 하루를 위한 한국어 개인용 TodoList 웹애플리케이션입니다.  
디자인 시스템 명세서([DESIGN.md](file:///c:/Users/User/Desktop/Antigravity/WEB/todo-list/DESIGN.md))의 디자인 토큰과 UI/UX 지침을 100% 준수하여 구현되었습니다.

---

## 1. 주요 기능

1. **할 일 추가**
   - Enter 키 또는 '추가' 버튼으로 즉시 등록
   - 앞뒤 공백 제거 및 빈 문자열/공백 입력 방지 안내
   - 최대 200자 제한
   - 한글 IME 조합 중(`isComposing`) 의도치 않은 중복 등록 완벽 방지
   - 등록 후 입력창 초기화 및 자동 포커스 유지
   - 최신 등록 항목 상단 배치
   - 필터/검색 조건에 의해 등록 직후 숨겨지는 경우 안내 배너 및 '전체 보기' 제공

2. **완료 상태 관리**
   - 체크박스 클릭 또는 항목 내용 클릭으로 완료/미완료 전환
   - 완료 항목에 취소선 및 텍스트 음영(`text-muted`) 스타일 적용
   - 헤더에 실시간 진행률(0~100%) 및 접근성 프로그레스 바 제공 (0개일 때 0% 오류 방지)

3. **내용 수정**
   - '수정' 버튼 클릭 시 인라인 편집 모드 전환 및 텍스트 자동 선택
   - Enter 키 또는 '저장' 버튼으로 저장, Esc 키 또는 '취소' 버튼으로 취소
   - 빈 문자열 저장 차단 및 에러 메시지 제공
   - 완료 상태 및 생성 시각(`createdAt`) 보존

4. **개별 삭제 및 실행 취소 (Undo)**
   - 개별 항목 삭제 시 즉시 목록에서 제거
   - 화면 하단에 실행 취소 토스트 알림 표시
   - 실행 취소 클릭 시 원래 데이터와 인덱스(순서) 그대로 복원
   - 빠른 연속 삭제 시 최신 삭제 1건이 실행 취소 대상임을 보장

5. **필터 및 검색 (교집합 지원)**
   - 상태 필터: 전체 / 진행 중 / 완료 (`aria-pressed` 지원)
   - 실시간 텍스트 검색: 대소문자 무구분 부분 문자열 검색
   - 검색어 원클릭 초기화 버튼
   - 검색 중일 때 스크린 리더 친화적 결과 건수 안내

6. **완료 항목 일괄 삭제**
   - 완료된 항목이 없으면 비활성화
   - 클릭 시 확인 모달 대화상자 표시 (삭제 대상 개수 명시)
   - 취소 시 데이터 유지, 삭제 시 완료 항목만 일괄 제거
   - 대화상자 Esc 닫기 및 포커스 트랩/복귀 지원

7. **로컬 자동 저장 및 복원**
   - `localStorage` 기반 안전한 자동 저장 (`todo-app:v1` 스키마)
   - 데이터 손상 또는 잘못된 JSON 감지 시 기존 데이터 덮어쓰기 방지 및 사용자 복구 안내
   - 용량 초과 또는 스토리지 접근 차단 시에도 앱 메모리 상태 유지 및 저장 실패 경고 표시

## 2. 기술 스택 및 구조

- **Frontend**: React 18, TypeScript 5, Vite 5
- **Style**: 순수 CSS + CSS Custom Properties (디자인 토큰)
- **Test**: Vitest 2, Testing Library (React, Jest-DOM, User-Event)
- **QA & Verification**: Chrome 내장 브라우저 에이전트를 통한 반응형(360px ~ 1280px) 및 상호작용 실시간 검증

```
todo-list/
├── src/
│   ├── components/       # Header, TodoInput, FilterSearch, TodoList, TodoItem, SummaryFooter, ConfirmDialog, UndoToast
│   ├── hooks/            # useTodos (비즈니스 로직 및 상태 관리)
│   ├── lib/              # storage.ts (안전한 스토리지 연동 및 스키마 검증)
│   ├── types/            # todo.ts (타입 인터페이스)
│   ├── styles/           # tokens.css (디자인 시스템 토큰), index.css (레이아웃)
│   ├── test/             # 단위/통합 테스트 (26개 테스트 케이스)
│   ├── App.tsx           # 메인 뷰 컴포넌트
│   └── main.tsx          # 엔트리포인트

├── package.json
└── vite.config.ts
```

## 3. 실행 및 검증 명령어

> **참고**: Windows 환경에서 실행 시 Node.js 경로를 포함하여 실행합니다.

### 의존성 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
# 접속 주소: http://127.0.0.1:5173/
```

### 단위 및 통합 테스트 실행
```bash
npm run test:run
```

### 타입 검사 및 프로덕션 빌드
```bash
npm run typecheck
npm run build
```

## 4. 저장 방식 및 제한사항

- **저장 범위**: 본 앱의 모든 데이터는 사용자의 **현재 웹 브라우저 로컬 저장소(`localStorage`)**에만 저장됩니다.
- **클라우드 동기화 없음**: 서버, 사용자 계정, 클라우드 데이터베이스 백업 기능이 없으므로 다른 기기나 다른 브라우저 간 동기화되지 않습니다.
- **다중 탭 동기화**: 단일 탭 사용을 기본으로 하며, 다른 탭에서 변경한 내역이 실시간 동기화되지 않습니다.
- **실행 취소 범위**: 개별 삭제 실행 취소는 가장 최근에 삭제된 **1건**에 대해서만 제공됩니다.
